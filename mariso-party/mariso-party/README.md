# マリソパーティー

ブラウザで動く3Dパーティーゲームです。Three.js製で、キャラクター選択→ミニゲーム選択→対戦、という流れで遊べます。

## 遊び方
1. `index.html` をダブルクリックしてブラウザで開く(Chrome / Edge 推奨。**インターネット接続が必要**です。Three.jsをCDNから読み込みます)
2. BOTの人数(0〜3人)と強さ(弱い/普通/強い/たつじん)を設定
3. 自分のキャラクターを10種類から選択
4. ミニゲームを10種類(バトロワ7 / チーム戦3)から選んでプレイ

## 操作方法
- 移動: `W A S D` または矢印キー
- ジャンプ / アクション: `スペース`
- ダッシュ: `Shift`

## 収録ミニゲーム
**バトロワ(個人戦・7種)**
1. 全力ダッシュ - ハードルジャンプレース
2. コインラッシュ - 降ってくるコインを集めろ
3. バランス島 - 傾く島から落ちるな(以前よりバランスがシビアに)
4. 玉転がしレース - 障害物を避けながらボールを押してゴールへ
5. イス取り合戦 - 踏むと1秒で崩れる100枚の床から落ちるな(Fall Guys風)
6. 的当てバトル - 左右に動く的を狙え
7. ジャンプ台合戦 - トランポリン相撲

**チーム戦(2vs2・3種)**
8. 綱引き対決 - タイミングよくタップして綱を引き寄せろ(音ゲー風)
9. 玉入れ対決
10. フィールドサッカー

## 技術構成
- Three.js (r160, CDN経由) による3Dレンダリング
- 自作の軽量物理演算(重力・摩擦・衝突・反発)
- BOT AIは反応速度・精度・ミス率・個体ごとの性格パラメータを持ち、難易度と個体差で多彩な動きをします
- キャラクター・ミニゲームはすべてオリジナルデザインです(既存作品のキャラクター/固有名詞は使用していません)

## 起動方法について
`index.html` をダブルクリックするだけで遊べます(通常の`<script>`読み込みに変更したため、`file://`から開いてもボタンが反応しない問題は発生しません)。もちろんローカルサーバー経由(`python3 -m http.server` など)で開いても問題なく動作します。
